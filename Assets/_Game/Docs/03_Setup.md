# 실행 방법

> 갱신: 2026-09-03. **기준 문서는 `00_HANDOFF.md`** 입니다. 이 파일은 "일단 돌려 보고 싶다"를 위한 축약본입니다.

Unity 에디터에서 스크립트 컴파일이 끝나면 상단 메뉴에 **`Rooftop Contract`** 가 생깁니다.

## 클릭 한 번

```
Rooftop Contract ▸ ★ BUILD EVERYTHING (전체 재생성)
```

끝입니다. 이 하나가 URP 머티리얼 변환 → 팔레트 텍스처 수정 → 빈 배역 자동 배정 →
**사무실 + 미션 3개 씬 생성 + NavMesh 베이크**까지 다 하고, 끝나면 **`Office` 씬을 열어 줍니다.**
**Play 를 누르면 됩니다.**

앞의 두 단계는 **이미 처리된 건 건너뜁니다.** 그래서 매번 눌러도 폴더 스캔 값만 듭니다.

> **씬은 소모품이고 생성기가 원본입니다.** `Office.unity` 와 `Mission1~3.unity` 는 매번 통째로
> 다시 만들어집니다. 씬을 손으로 편집하면 다음 빌드에 날아갑니다 — 고칠 곳은
> `MissionSet.asset` · `CastingConfig.asset` 또는 `Editor/RC_*.cs` 입니다.

개별 단계만 따로 돌리는 메뉴는 전부 `Rooftop Contract ▸ 도구/` 아래에 있습니다 (`00_HANDOFF.md` 2절).
**캐릭터를 새로 추가했을 때만** `도구 ▸ 캐릭터 — 리그 Humanoid 변환` 을 먼저 돌리세요
(FBX 전체 재임포트라 느려서 ★ 에 넣지 않았습니다).

## 조작

| 입력 | SNIPER | DEFENSE |
|---|---|---|
| 마우스 | 조준 | 조준 |
| 좌클릭 | 사격 | 사격 |
| **우클릭** | **배율 1x → 8x → 16x 순환** | **홀드 = 엄폐 해제 + 사격 허용** |
| Shift | 호흡 정지 (흔들림 0.18배) | — |
| A / D | — | 엄폐 라인 따라 좌우 |
| R | — | 재장전 / 결과 화면에서 재시작 |
| SPACE | — | 결과 화면에서 사무실 복귀 |
| ESC | 일시정지 메뉴 | 일시정지 메뉴 |

탄약은 계약마다 다릅니다 (6 / 5 / 4발).

## 플레이 흐름

1. **사무실**에서 시작합니다 (빌드 인덱스 0). 책상 위 서류 3장 중 하나를 고르고 `SPACE`.
   계약은 **순서가 없고**, 몇 번이든 다시 고를 수 있습니다.
2. 미션 씬이 열리면 짧은 **인트로 워크** 뒤 이미 난간에 거치된 저격총 앞에 섭니다.
3. 우클릭으로 8배율. 소총은 **그 계약의 거리로 영점이 잡혀 있으므로** 조준점에 그대로 맞습니다.
4. 첫 발을 쏘면 — **탄이 도착한 순간** 경호원 머리 위에 `!` 가 뜨고 VIP에게 밀착합니다.
   방패가 닫히기까지의 짧은 시간이 **두 번째 사격의 창**입니다.
5. 첫 발로부터 **17초** 뒤, 뒤쪽 계단실에서 돌격대가 올라옵니다.
6. **40초**를 버티면 헬기가 들어옵니다. 헬기가 도착할 때까지 **계속 싸웁니다.**
7. 결과 화면 → `SPACE` 로 사무실 복귀. 표적을 죽였으면 그 서류에 **"사망"** 도장이 찍힙니다.

## 튜닝 지점

> **씬을 다시 빌드하면 인스펙터 값은 초기화됩니다.** 확정된 값은 반드시 아래 "고칠 곳"에 반영하세요.

| 바꾸고 싶은 것 | 고칠 곳 |
|---|---|
| 계약별 탄약·거리·고도·경호원 수·타이머·베뉴·난이도 | `_Game/MissionSet.asset` **+ `MissionSet.BuildDefaults()`** |
| 배역, 히트박스, 무기 그립 | `_Game/CastingConfig.asset` |
| 배율, 반동, 탄속, 영점 | `Player/SniperRig.cs` 필드 기본값 |
| 밀착 반경, 대형 각도, 조임 시간 | `AI/ProtectionDetail.cs` |
| 적 스폰 간격, 동시 인원, 후반 압박 | `AI/AssaultDirector.cs` ★접근 속도는 전부 여기 |
| 맵 지오메트리 (옥상, 엄폐물, 스카이라인) | `Editor/RC_MapBuilder.cs` |
| 사무실 (방, 책상, 핀보드, 사진 부스) | `Editor/RC_OfficeBuilder.cs` |

`MissionSet.asset` 만 고치면 안 되는 이유: `assetVersion` 이 `MissionSet.CurrentVersion` 보다
낮아지는 순간 생성기가 `BuildDefaults()` 로 **덮어씁니다**.
